# YJ 스튜디오 통합 관제센터 기획안

> **작성일:** 2026-11-26  
> **위치:** `회사홈페이지` (`/admin`)  
> **핵심 목표:** 흩어진 4개 앱(울동네, 찻잔타로, 꿈소반, 대나무속풀이)의 관리자 기능과 블로그 초안 작성을 하나로 합치고, 전 앱 방문자·AI 상태·비용·플레이스토어 현황·긴급 알림을 한눈에 관제한다.

## 1. 왜 통합 관제센터가 필요한가요?
- 기존에는 앱마다 `/admin` 주소에 따로 들어가서 글을 쓰고 상태를 확인해야 했습니다.
- 앞으로 새 앱이 늘어날수록 관리가 번거로워지므로, 회사 홈페이지에 **대표님 전용 종합 관제 본부**를 세우고 새 앱을 **레고 블록처럼 끼워 넣는 구조**로 만듭니다.

## 2. 핵심 구성 (4대 메뉴)
1. **종합 현황판:** 전체 앱 방문자 수, AI 연결 상태 신호등(정상/주의/오류), 일별·월별 예상 AI 비용, 매출 vs 비용 순수익 추이
2. **통합 블로그 작업실:**
   - **울동네:** 복지 정보 블로그 초안 검수·발행 및 게시 상태 관리
   - **찻잔타로 / 꿈소반 / 대나무속풀이:** AI 초안 생성(각 앱 맞춤 글쓰기 지침 포함), 글 작성·수정·발행·삭제를 한 화면에서 전환하며 처리
3. **스토어 · 문의함:**
   - 구글 플레이스토어 출시 앱(`톡비서`, `오답정복`) 댓글·별점·다운로드 수 확인
   - 회사 홈페이지 및 앱 고객 문의 통합 확인
4. **앱 블록 관리 & 긴급 알림:**
   - **블록식 확장:** 새 앱 추가 시 이름·종류·켤 기능 스위치만 등록하면 관제판에 자동 추가
   - **긴급 알림(구현 틀 우선 구축):** AI 오류 급증, 일일 비용 상한 초과, 저평점 리뷰 발생 시 대표님 **이메일 + 텔레그램**으로 경보 발송 (추후 열쇠만 넣으면 즉시 가동)
   - **출시·심사 필수 점검표:** 앱별 광고 목업 정리, 이용약관·개인정보처리방침 확인 체크리스트

## 3. 기존 앱과 충돌하지 않나요?
- 기존 앱의 관리자 페이지를 억지로 뜯어내지 않고 그대로 둡니다.
- 통합 관제센터가 각 앱의 **글 보관 창고**에 직접 연결되어 글을 저장·발행하므로, 기존 관리자 페이지에서도 똑같은 글이 그대로 보입니다. (무중단·무위험 방식)

## 4. 단계별 구축 로드맵
- **1단계 (지금 착수):** 통합 관제실 보안 잠금 + 블록식 앱 명세서 구조 + 통합 블로그 작업실(4개 앱 연동) + 종합 현황판/긴급 알림 틀 + 노하우 문서화
- **2단계:** 전 앱 방문자·AI 호출 상태/비용 실시간 수집 연결 + 이메일·텔레그램 긴급 경보 실제 발송 연결
- **3단계:** 구글 플레이스토어 리뷰·일일 다운로드 보고서 자동 동기화 + 매출 순수익 비교판 완성
