# 한글 다마고치 (가칭) 프로젝트 작업 노트

## 1. 프로젝트 개요
- **기획 비전**: 한글을 전혀 모르는 3~6세 유아가 **주 4일(1회 10분)** 반려 캐릭터와 놀아주며, **9개월(총 36주 / 144회 세션)** 만에 초등학교 입학 전 수준(받침, 복합모음, 기초 동화책 읽기)까지 마스터하는 에듀테인먼트 앱.
- **핵심 루프**: 주 4일 한글 놀이터 세션 ➔ 사과 획득 ➔ 말랑이 맘마 먹이기 ➔ 4단계 진화 및 초등 입학 졸업장 수여.

## 2. 9개월(36주) 4단계 커리큘럼 체계
1. **1단계 (1~2개월 / 1~8주):** 자음 14자 소리와 모양 매칭 (알 ➔ 아기 슬라임 ➔ 왕관)
2. **2단계 (3~4개월 / 9~16주):** 기본 모음 10자 및 자모 결합 원리 ('가'~'하' / 꼬마 슬라임 ➔ 아기 날개)
3. **3단계 (5~6개월 / 17~24주):** 7대 대표 받침(ㅇ, ㅁ, ㄴ, ㄹ, ㅂ, ㄱ, ㅅ) 정복 (마법 요정 슬라임 ➔ 마법 지팡이)
4. **4단계 (7~9개월 / 25~36주):** 쌍자음/복합모음 및 초등 1학년 국어 낱말·문장 읽기 (학사모 마스터 슬라임 & 초등 입학 수료증)

## 3. 4대 욕구 학습 보상 및 자동 수면 시스템
- **맘마 (먹이주기)**: 1회 학습(8~10분) 완료 시 '하루치 사과 3개' 지급 ➔ 아이가 원하는 시간 간격으로 직접 먹여줌 (먹이 부족 시 학습 유도).
- **목욕 (청결)**: 학습 완료 시 '무지개 비누/딸기 칫솔' 획득 ➔ 거품 목욕 인터랙션으로 깨끗하게 씻겨줌.
- **놀이 (교감)**: 학습 완료 시 '축구공/장난감' 획득 ➔ 캐릭터와 공 튕기기 및 댄스 상호작용.
- **재우기 (수면 루틴 & 스마트폰 보호)**: 
  - 당일 학습을 최종 완료하면 은은한 달빛 취침 버튼 활성화.
  - 버튼을 누르면 침대로 가서 잠들며, 누르지 않아도 일정 시간(유아 보호 타이머 or 밤 9시)이 지나면 하품 후 스스로 침대에 누워 잠듦 (부모 개입 없는 자연스러운 수면 유도).

## 4. 아이소메트릭 3D 방 및 가구 실시간 동기화
- **공간 연출**: 아래로 내려다보는 쿼터뷰(Isometric) 입체 룸으로 구성 (좌/우 벽면, 창문, 한글 액자, 원목 쉐브론 바닥).
- **4대 입체 가구 배치**:
  - `침대 💤`: 뒤쪽 상단, 취침 모드 시 말랑이가 이동하여 꿀잠.
  - `먹이통 🍎`: 좌측 앞쪽, 학습 진행 시 사과가 채워지며 탭 시 직접 식사.
  - `세면도구 🧼`: 우측 뒤쪽, 학습 진행 시 비누와 거품이 채워지며 탭 시 목욕.
  - `놀이상자 ⚽`: 우측 앞쪽, 학습 진행 시 장난감이 채워지며 탭 시 놀이.
- **실시간 학습 채우기 루프**:
  - 유아가 퀴즈를 1문제 풀 때마다 즉시 방 안의 해당 가구(1단계: 사과, 2단계: 비누, 3단계: 장난감)에 아이템이 퐁! 하고 채워지며 시각적 피드백 제공.
  - 방 안의 가구를 직접 손가락으로 누르면 캐릭터가 그 자리로 통통 달려가서 상호작용 수행.
- **오픈소스(Lottie 스타일) 3.2~3.6초 다단계 케어 모션**:
  - `맘마 먹기(3.3초)`: 사과 포물선 등장 ➔ 아삭아삭 3단계 씹기(볼 빵빵+큰 입) ➔ 만족스러운 눈웃음 및 하트 피니시.
  - `목욕하기(3.6초)`: 비누 쓱싹 문지르기 ➔ 몽글몽글 거품 구름 부풀기 ➔ 시원한 물줄기 헹굼 ➔ 반짝반짝 광채 피니시.
  - `놀아주기(3.6초)`: 공 1차 헤딩 ➔ 공중 360도 덤블링 묘기 ➔ 별 폭죽 & 승리 엉덩이 댄스 피니시.
- **4대 상태별 직관적 캐릭터 모션**:
  - `배고픔`: 몸이 홀쭉해지며 떨림 + 배 옆 "꼬르륵~ 💭" 진동 + 뾰루퉁한 입.
  - `꾀재재함`: 칙칙한 색감 변화 + 흙 얼룩 3곳 & 파리 윙윙 + 간지러워 몸 떨기.
  - `심심함`: 바닥에 납작 엎드려 뒹굴 + 반쯤 감긴 지루한 눈 + 한숨("휴우... 💧").
  - `졸림`: 꾸벅꾸벅 고개 숙이기(화들짝 깨기 반복) + 입 벌려 하품 + 부풀어 오르는 콧방울.

## 5. 부모님 공간 (비밀번호 잠금 + 슬라이드 설정창)
- **진입 경로**: 좌측 상단 `[🐣 말랑이 ⚙️]` 배지 클릭 ➔ 4자리 숫자 비밀번호 입력 모달 (초기 비밀번호 `0000`).
- **슬라이드 설정창 구성**:
  1. `구독 및 결제 관리`: 월간/연간 플랜 선택 및 결제 미리보기 목업 모달.
  2. `아이 학습 진도 확인`: 현재 커리큘럼 단계, 오늘 푼 문제 수, 모은 별, 9개월 정복 진도율 표시.
  3. `사용시간 및 취침시간 설정`: 하루 최대 사용시간 제한 선택, 자동 취침 예약 토글 및 시각 선택.
  4. `사용자 설정`: 캐릭터 이름(애칭) 변경, 효과음 켜기/끄기, 부모님 비밀번호 변경.
  5. `하단 안내 링크`: 이용약관, 개인정보처리방침, 이용방법 안내 (목업 모달 오픈).

## 6. 3D 동화풍 클레이 그래픽 업그레이드 (1단계)
- **방 배경 (`assets/room_bg.jpg`)**: 파스텔 크림/옐로우 벽면, 아치형 햇살 창문, 민트 벽시계, `ㄱ ㄴ ㄷ` 원목 액자, 헤링본 원목 마루와 하늘색 별 러그가 어우러진 3D 클레이/동화풍 아이소메트릭 방 적용.
- **4대 가구 & 캐릭터 투명 일러스트**: 침대(`furn_bed.png`), 먹이통(`furn_bowl.png`), 세면도구(`furn_wash.png`), 놀이상자(`furn_chest.png`), 말랑이(`char_malrang.png`)를 3D 클레이풍으로 제작해 투명 배경 처리 후 배치. 학습 시 채워지는 사과·비누·장난감 보상과 4가지 상태 모션은 가구·캐릭터 위에 자연스럽게 연동됨.

## 7. 부드러운 움직이는 벡터 애니메이션 결합 (2단계)
- **로컬 애니메이션 재생기 및 4대 연출 파일 (`assets/lottie/`)**: 외부 네트워크에 의존하지 않도록 재생기(`lottie.min.js`)와 4가지 전용 애니메이션(`hearts_sparkle.json`, `soap_bubbles.json`, `play_stars.json`, `celebrate_confetti.json`)을 내장.
- **연동 지점**: 밥 먹기(하트·별빛), 목욕하기(무지개 비눗방울), 놀아주기(회전 별 파티클), 한글 퀴즈 정답(화면 전체 축하 폭죽) 순간마다 끊김 없이 60프레임으로 재생됨.

## 8. 실시간 3D 입체 공간 전환 (3단계)
- **전용 실시간 3D 방 (`three-room.js`)**: 외부 서버 연결 없이 내장된 3D 엔진(`assets/three/three.min.js`)으로 원목 마루, 별 러그, 창문(낮 해/밤 달 전환), 민트 시계, `ㄱ ㄴ ㄷ` 액자, 4대 3D 가구, 3D 말랑이 캐릭터를 실시간 렌더링.
- **터치 시점 회전 & 직접 터치**: 손가락이나 마우스로 방을 드래그해 각도를 돌려볼 수 있으며, 3D 가구·바닥·말랑이를 터치하면 기존 돌봄/수면/학습 보상 채우기(3D 사과·비누·공 쌓임)와 100% 연동됨.
- **12가지 자율 일상 동작 AI**: 사용자와 교감이 없을 때(약 3.8초 이후) 방 구경, 데굴데굴 구르기, 엉덩이 춤, 헤드폰 쓰고 음악 듣기, 그림책 읽기, 혼자 공놀이, 기지개 켜기, 팽이 돌기, 창밖 구경, 노래 부르기, 까꿍 놀이, 러그 위 꼼지락 휴식 등 12가지 동작과 전용 3D 소품(헤드폰·그림책·음표·공)을 랜덤으로 반복하며, 사용자가 터치하면 즉시 교감 모드로 전환됨.
