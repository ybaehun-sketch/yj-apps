# 📝 오답정복 — 앱 작업 노하우 및 관리 기록

## 1. 앱 핵심 구조 및 주의사항
- **기술 구성:** 순수 웹 표준(HTML, CSS, 바닐라 ES 모듈 JavaScript). 별도 번들러 없이 정적 서빙 가능.
- **모듈 캐시 관리:** 브라우저 캐시 방지를 위해 `index.html` 및 `app.js`, `modules/trialLicense.js` 내 import 경로에 버전 쿼리스트링(`?v=20261121free...`)을 동기화하여 유지 관리해야 함.
- **데이터 보관 원칙:** 회원가입 없이 사용자 기기 로컬 저장소(IndexedDB / LocalStorage)에 보관.

## 2. 플레이스토어 심사 대비 무료 모드 전환 (2026-11-21)
- **배경:** 구글 플레이 인앱 결제 모듈이 없는 상태에서 가짜 결제/구독 UI가 노출될 경우 심사 거절(반려) 위험 방지.
- **전략적 브랜딩:** '영구 완전 무료'로 공표할 경우 추후 유료 전환 시 사용자 반발이 생길 수 있으므로, **「출시 기념 특별 한정 무료 이벤트」** 프레임으로 정돈. (구글 심사관 통과 + 사용자 혜택 체감 + 추후 정식 유료화 시 자연스러운 전환 명분 확보)
- **적용 내용:**
  - `modules/trialLicense.js`: 항상 `state: 'purchased'`, `purchased: true`를 반환하여 결제 강제나 만료 팝업 차단.
  - `modules/i18n.js`: 한국어, 영어, 일본어 번역 문구를 모두 '출시 기념 무료 이벤트', '이벤트 적용 중'으로 전환.
  - 하단 링크: '이용방법', '이용약관', '개인정보처리방침' 클릭 시 회사 공식 홈페이지(`https://yjstudio.app/wrongnote`) 웹페이지가 열리도록 연동.
