# 📝 오답정복 — 앱 작업 노하우 및 관리 기록

## 1. 앱 핵심 구조 및 주의사항
- **기술 구성:** 순수 웹 표준(HTML, CSS, 바닐라 ES 모듈 JavaScript). 별도 번들러 없이 정적 서빙 가능.
- **모듈 캐시 관리:** 브라우저 캐시 방지를 위해 `index.html` 및 `app.js`, `modules/trialLicense.js` 내 import 경로에 버전 쿼리스트링(`?v=20261121free...`)을 동기화하여 유지 관리해야 함.
- **데이터 보관 원칙 (로그인 미도입 확정):** 회원가입·로그인 기능을 추후에도 넣지 않고 사용자 기기 로컬 저장소(IndexedDB / LocalStorage)에만 보관. 기기 변경 시 저장된 문제를 옮길 수 없음을 이용방법 및 이용약관(`yjstudio.app/wrongnote`)에 명확히 고지.

## 2. 플레이스토어 심사 대비 무료 모드 전환 (2026-11-21)
- **배경:** 구글 플레이 인앱 결제 모듈이 없는 상태에서 가짜 결제/구독 UI가 노출될 경우 심사 거절(반려) 위험 방지.
- **전략적 브랜딩:** '영구 완전 무료'로 공표할 경우 추후 유료 전환 시 사용자 반발이 생길 수 있으므로, **「출시 기념 특별 한정 무료 이벤트」** 프레임으로 정돈. (구글 심사관 통과 + 사용자 혜택 체감 + 추후 정식 유료화 시 자연스러운 전환 명분 확보)
- **적용 내용:**
  - `modules/trialLicense.js`: 항상 `state: 'purchased'`, `purchased: true`를 반환하여 결제 강제나 만료 팝업 차단.
  - `modules/i18n.js`: 한국어, 영어, 일본어 번역 문구를 모두 '출시 기념 무료 이벤트', '이벤트 적용 중'으로 전환.
  - 하단 링크: '이용방법', '이용약관', '개인정보처리방침' 클릭 시 회사 공식 홈페이지(`https://yjstudio.app/wrongnote`) 웹페이지가 열리도록 연동.

- **복습 버튼 문구:** `← 왼쪽으로 던지세요` / `오른쪽으로 던지세요 →` (X, 체크 아이콘 제거).
- **쓱-지우개 개선:** 최소 크기 `3`으로 축소, 마우스/터치 위치에 맞춘 동그라미 크기 미리보기 커서 추가, 색상 필터 버튼 제거(연필·볼펜 모두 지워짐), 사진 업로드 직후 기본 도구를 미선택(`none`)으로 설정.
- **AI 사진→텍스트 변환:** 2차 업데이트(월 4,900원 유료 구독 모델)로 보류.

## 5. 안드로이드 앱 포장(PWA → TWA) 및 배포 현황
- **배포 방식:** `톡비서`와 동일하게 PWA + Cloudflare Workers 정적 호스팅 + PWABuilder 패키징 방식.
- **배포 주소:** `https://wrongnote.ybaehun.workers.dev` (별도 도메인 미구매, 앱 전용 사용).
- **앱 고유 이름(Package ID):** `app.yjstudio.wrongnote`
- **구성 파일:** `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`, `favicon.png`, `.well-known/assetlinks.json`
- **다음 할 일 (구글 플레이 스토어 출시 등록):**
  1. PWABuilder 안드로이드 패키지 내 `assetlinks.json` 서명 지문을 `.well-known/assetlinks.json`에 반영하고 `wrongnote.ybaehun.workers.dev`에 재배포 완료 (2026-11-21).
  2. 한·영·일 3개 국어 스토어 등록 자산(`store-assets/` 내 스크린샷 각 6장, 그래픽 이미지 1024x500, 앱 아이콘 512x512) 제작 및 플레이 콘솔에 `오답정복.aab` 업로드 완료.
  3. **남은 단계:** 구글 플레이 콘솔 `계정 세부정보` → `한국 개발자의 경우 추가 정보 필요`에 통신판매업 신고번호(전자상거래 라이선스 번호) 입력 후 `게시 개요 → 검토를 위해 변경사항 전송` 클릭.
  4. **구글 플레이 출시 후 주소창 노출 해결 (2026-11-25):** 정식 출시 시 구글 플레이 자체 앱 서명 키(`1E:A6:...`)로 재서명되므로 `.well-known/assetlinks.json`에 업로드 키(`5E:3B:...`)와 함께 앱 서명 키 지문을 병기하여 재배포 필요.

## 6. 7일 무료 체험 + 3,900원 평생 소장 결제 연동 (2026-11-25)
- **정책 확정:** 7일 무료 체험 후 **3,900원(약 3달러) 1회 결제 평생 소장** 모델 적용. (체험 만료 시 기존 문제 복습은 계속 가능하며, 새 오답 올리기 시 결제 안내 창 표시)
- **결제 연동 구조:** `톡비서`에서 검증된 구글 플레이 인앱 결제 방식(`modules/playBilling.js`)을 재활용. 앱 실행 시 자동 구매 복원 확인 및 결제 화면 내 '구매 복원' 버튼 포함.
- **구글 플레이 콘솔 등록 상품 코드:** `wrongnote_lifetime` (1회성 인앱 상품, 3,900원)
- **주의사항:** 실제 앱에서 결제가 동작하려면 구글 플레이 콘솔에 위 상품 코드를 등록하고, 구글 플레이 결제가 활성화된 새 안드로이드 앱 패키지(`.aab`)로 스토어 업데이트가 필요함.
