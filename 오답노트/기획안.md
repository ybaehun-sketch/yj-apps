# 📝 오답노트 — 최종 실전 기획안

## 1. 핵심 컨셉
- **대상:** 시험을 준비하는 사람이라면 누구나 (학생, 자격증, 어학, 공무원 등 범용)
- **핵심 가치:** 회원가입·복잡한 설정 없이 **"틀린 문제만 가볍게 올려 내 필기를 지우고 다시 풀다가, 내가 정한 횟수만큼 맞히면 미련 없이 목록에서 자동 삭제되는"** 가장 단순하고 쾌감 있는 오답노트

## 2. 우리만의 3대 핵심 킥
1. **「쓱-지우개」 (새 문제로 변신):** 문제 사진 속 내가 푼 볼펜 체크·밑줄·채점 자국 위를 손가락으로 쓱 문지르면, 주변 종이 색에 맞춰 감쪽같이 지워져 방금 인쇄한 새 문제처럼 다시 풀 수 있음
2. **「고민 없는 10초 가림막 복습」:** 목록을 뒤질 필요 없이 `바로 풀기`를 누르면 또 틀렸던 문제부터 화면 가득 뜨고, 정답·해설은 가림막으로 가려져 있어 터치 한 번으로 확인 후 `맞혔어요 / 또 틀렸어요`로 즉시 다음 문제 이동
3. **「시험 전날 나만의 A4 시험지 뽑기」:** 끝까지 틀린 약점 문제만 모아 깔끔한 인쇄용 A4 시험지(앞장 문제지 + 뒷장 정답지)로 한 번에 내보내기

## 3. 초심플 3화면 구성 및 수험생 무결점 흐름
1. **홈 (내 오답 목록)**
   - **상단:** 가로 1줄 과목 버튼 (`전체`, 사용자 추가 과목, `+`) + `또 틀린 문제만` 스위치 + `바로 풀기` / `시험지 뽑기` 버튼
   - **중앙:** 등록한 오답 카드 목록 (깔끔한 문제 사진, 한 줄 메모, 틀린 횟수 표시)
   - **우측 하단:** 엄지로 바로 누르는 큰 `+ 오답 올리기` 버튼
2. **오답 올리기 (3초 등록)**
   - 문제 사진 올리기 (필요 시 손가락으로 문제 영역만 자르기 + **쓱-지우개**로 기존 필기 지우기)
   - 정답·해설 넣기 (정답 사진 1장 추가 또는 한 줄 메모)
   - 과목 선택: **직전에 고른 과목을 자동 기억**해 두어 바꿀 때만 1번 터치 (미선택 시 전체/미분류로 즉시 저장)
3. **다시 풀기 (가림막 복습)**
   - 현재 선택한 과목(또는 전체) 중 또 틀렸던 문제 우선 출제
   - 문제만 크게 보이고 정답·해설은 **반투명 가림막**으로 가림
   - **[정답 보기]** 터치 시 가림막 해제 → 하단 **[맞혔어요 ✅]** / **[또 틀렸어요 🔁]** 누르면 즉시 다음 문제로 전환 (연속 정답 시 ‘완전 정복’ 표시)

## 4. 수익화 구조 (광고 없는 7일 체험 + 1회성 평생 판매)
- **처음 7일 (무료 체험):** 광고 없이 모든 핵심 기능(오답 등록, 쓱-지우개, 가림막 복습, 시험지 뽑기)을 100% 자유롭게 체험
- **7일 이후 (구글 스토어 1회성 판매 — 약 3달러):** 매달 빠져나가는 정기 구독이 아닌 **단 한 번 결제(약 3달러)**로 평생 소장 전환 (기존에 저장한 오답 복습은 계속 가능하되, 새 오답 추가 및 시험지 뽑기는 평생 소장 후 이용)

## 5. 공용 레고 부품 창고(`c:\dev\공용_부품_창고`) 연계 계획
- 이번 프로젝트에서 검증되는 **① 사진 자르기 + 쓱-지우개**, **② 가림막 복습 카드**, **③ 가로 1줄 과목 버튼(직전 선택 기억)**, **④ A4 시험지 인쇄 내보내기**를 독립된 레고 부품으로 정리해 창고에 등록한다.
