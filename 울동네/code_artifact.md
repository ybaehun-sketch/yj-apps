# 📋 프로젝트 마스터 기획서: AI 순찰대 기반 전국구·로컬 생활복지 큐레이션 플랫폼

> **문서 목적:** 1인 개발자가 최소한의 고정비(월 3만 원 이내)로 웹 블로그(애드센스)와 모바일 앱(애드몹 네이티브·전면광고)의 이중 수익 파이프라인을 구축하고, 홍천군에서 시작해 강원도 거쳐 전국 226개 시·군·구로 확장하기 위한 최종 실행 기획서.

---

## 1. 핵심 문제 정의 및 차별화 전략

### 1.1. 기존 서비스의 한계
* **정부 앱(보조금24, 복지로):** 공인인증서·간편인증 로그인 장벽이 높고, 행정 용어 그대로 적혀 있어 부모님이나 어르신이 직관적으로 이해하기 어렵다. 또한 단기 모집 공고(겨울방학 돌봄교실, 선착순 프로그램 등)는 누락되는 경우가 많다.
* **지자체 홈페이지:** 주민이 매일 군청·교육지원청·가족센터 게시판을 일일이 들어가서 입찰·공사 공고 틈바구니에서 내 혜택을 찾아내야 하는 번거로움이 있다.

### 1.2. 우리의 해결책 (Killer Features)
1. **로그인 없는 10초 세팅:** 앱 설치 후 `[내 동네 선택]` + `[관심 키워드 입력]` 단 두 단계로 모든 세팅 끝.
2. **AI 순찰대 자동 수집:** 중앙 공공데이터 API(전국구) + 지자체 게시판(로컬)을 AI가 매일 순찰하여 입찰·공사는 버리고 돈과 혜택이 되는 공고만 골라낸다.
3. **관심 키워드 즉시 푸시:** 내가 등록한 `#방학돌봄`, `#난방비` 공고가 뜨면 놓치지 않고 스마트폰 푸시로 즉시 알려준다.

## 2. 정보 수집 및 콘텐츠 생산 아키텍처 ('AI 정보 수집 팀')

### 2.1. 2-Track 하이브리드 수집 전략
| 구분 | 수집 대상 | 역할 및 특징 | 유지보수 난이도 |
| :--- | :--- | :--- | :--- |
| **트랙 A: 중앙 정보국** | 공공데이터포털 API 2종 (`보조금24`, `지자체 복지서비스`) + `familynet.or.kr`(전국 가족센터) | 전국 모든 시·군·구의 상시 복지·지원금 데이터를 표준 규격으로 빈틈없이 수급 | **0 (완전 자동)** |
| **트랙 B: 전국 AI 순찰대** | 각 시·군·구청 대표 게시판 (`고시/공고`, `군정소식`) + 거점 지역 교육지원청 | 방학돌봄, 선착순 체험, 지역 바우처 등 게시판에만 뜨는 따끈한 로컬 공고 족집게 추출 | **극소 (URL 명단만 관리)** |

### 2.2. 웹 블로그 vs 모바일 앱 역할 분리 (품질 & 수익 최적화)
* **웹 블로그 (SEO 검색 유입 전용):**
  * 전국구 지원금이나 내용이 풍부한 핵심 복지 제도(`publish_to_blog = true`)만 선별해 발행.
  * **30가지 글맛 엔진 + 실생활 절약 꿀팁 + 준비서류·탈락 주의사항 체크리스트**를 결합해 AI 저품질 필터링을 회피하고 네이버·구글 검색 상위 노출 유도.
* **모바일 앱 (초밀착 피드 & 알림 전용):**
  * 전국구 소식은 물론, 모집 인원이 적은 단기 로컬 공고(`publish_to_blog = false`)까지 **100% 전부 수용**.
  * **첨부파일(HWP·PDF) 전용 공고 대응:** 지자체 게시판 특성상 본문 없이 첨부파일에만 상세 내용이 있는 경우, 무리한 파일 변환 대신 제목·게시일·담당부서 기반 핵심 요약 후 **`[원문·첨부파일 바로 확인]`** 버튼으로 즉시 연결.
  * 블로그 글이 있는 소식은 웹 블로그로 연결해 애드센스 수익을 보태고, 단기 공고는 앱 내 핵심 요약 후 공고 원문으로 연결.

## 3. 모바일 앱 UX/UI 및 이중 수익화 설계

### 3.1. 사용자 여정 (User Flow)
1. **온보딩 (10초):** 지역 선택(`강원특별자치도 > 홍천군`) → **5대 표준 관심 분야 + 추천 키워드 칩 선택**(직접 입력 시 동의어 자동 매핑으로 알림 누락 방지) → 완료.
2. **메인 피드 화면:**
   * 상단: 지역 변경 드롭다운, 키워드 관리, 글씨 크기 조절(`가+`).
   * **카드 배열 순서 설정:** 사용자가 설정에서 `[관심 키워드 우선순(기본)]` / `[마감 임박순(D-Day)]` / `[최신 등록순]` 중 직접 선택 가능.
   * **깔끔한 카드 UI:** 화면 하단을 가리는 지저분한 배너 광고 완전 제거.
   * **스토어 심사 대비 투명성 고지:** 모든 화면 하단 및 상세 화면에 **"정부·지자체 공식 앱이 아닌 민간 큐레이션 서비스이며, 최종 확인은 공식 출처에서 진행해야 함"**을 명확히 표기하고, 회사 홈페이지(`yjstudio.app`) 전용 약관·개인정보처리방침 연결.

### 3.2. 이중 광고 수익화 퍼널 (AdMob + AdSense)
1. **1차 수익 (피드 탐색 중 - 네이티브 광고):**
   * 카카오톡 채팅목록·당근마켓 피드처럼 **소식 카드 3~4개당 1개 비율**로 일반 카드와 똑같은 디자인의 네이티브 광고 배치 (`[AD]` 배지 명확 표기).
2. **2차 수익 (상세 진입 후 행동 시 - 쿨타임 랜덤 전면광고 & 웹 연결):**
   * 카드 터치 → AI 핵심 요약 확인 → 하단 **`[관련 출처 링크 / 신청 바로가기]`** 클릭 시:
     * **랜덤 확률(40~50%) + 쿨타임(3~5분 간격 제한)** 조건 충족 시에만 전면광고 1회 노출 후 원문 링크 오픈.
     * 광고 미로딩 시 대기 없이 즉시 원문 오픈 (이탈 방지).
   * 심층 콘텐츠가 있는 공고는 내 웹 블로그 상세 페이지로 연결하여 **애드센스 페이지뷰 동시 확보**.

## 4. 비용 구조 및 전국 확장 로드맵

### 4.1. 월간 예상 유지비 시뮬레이션 (극강의 가성비)
* **호스팅 & DB:** Cloudflare Pages + Workers 무료 티어 / Supabase 무료 티어 (**0원**)
* **AI API 호출 비용 (페이지 해시 변경 감지 + 경량 모델 2단계 분리 적용 시):**
  * **1단계 (홍천군 단독):** 월 **500원 미만**
  * **2단계 (강원도 18개 시·군):** 월 **1,500원 ~ 3,000원**
  * **3단계 (전국 226개 시·군·구):** 월 **15,000원 ~ 25,000원** (넉넉히 월 3만 원 예산이면 전국구 가동 가능)

### 4.2. 단계별 실행 로드맵
* **지금 당장 (3일 집중 스프린트):**
  * **Day 1:** Supabase DB 스키마 생성 + 공공데이터 API 및 홍천군(군청·교육청·가족센터) 수집/글맛 워커 구축.
  * **Day 2:** Next.js 웹 블로그 + 아침 5분 검토 & FCM 푸시 발송용 `/admin` 페이지 배포 (`*.pages.dev`).
  * **Day 3:** 모바일 앱 MVP(온보딩, 피드 정렬, 네이티브/쿨타임 전면광고, FCM 토픽 수신) 빌드 및 실사용 테스트.
* **확장기 (1개월 이후 & 운영 자동화 전환):**
  * **1단계(홍천군):** 아침 5분 전수 검토·발행으로 필터링·글맛 튜닝 완료.
  * **2~3단계(강원도 18개 시·군 → 전국 226개 시·군·구):** 일일 수집량 증가에 대비해 중앙 API 및 AI 확신도(90점 이상) 공고는 **자동 발행**하고, 불확실한 글만 검토함에 남기는 **예외 검토 체계**로 전환하여 1인 운영 한계 돌파.
