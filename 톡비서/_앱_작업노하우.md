# 톡비서 앱 작업 노하우 및 핵심 결정사항

## 1. 출시 및 배포 전략 (대표님 확정 지시: 2026-11-23)
- **웹 배포 안 함:** 일반 웹 서비스로는 배포하지 않음.
- **구글 플레이스토어(안드로이드) 우선 출시:** 현재 구글 플레이스토어 심사 진행 중이며, 안드로이드 스토어 심사 통과 및 출시를 최우선으로 진행함.
- **애플 앱스토어(iOS) 후속 출시:** 안드로이드에서 일정 수준의 수익이 발생한 이후에 애플 앱스토어에 올릴 예정임.
- **푸시 알림 방향:** 추후 모바일 푸시 알림 연동 시에도 위 전략에 맞춰 안드로이드 환경 중심으로 우선 고려함.

## 2. 안정성 및 안전장치 이력
- AI 응답 지연/실패 시에도 사용자 메모 원문을 '기타' 카테고리로 우선 저장하고 안내 문구를 표시하도록 보강 (`src/lib/notes.functions.ts`).
- 외부 웹페이지 및 유튜브 링크 정보 조회에 5초 대기 시간 제한 공용 적용 (`fetchWithTimeout`).
- **Gemini 지역 제한 우회 및 배포 주의사항:** 홍콩(HKG) 등 지원 불가 엣지 지역에서 Gemini 호출이 막히는 문제를 해결하기 위해 서부 미국(`wnam`) 프록시 워커(`tokbiseo-gemini-proxy`)를 Service Binding(`GEMINI_PROXY`)으로 연결함. **`npm run build` 실행 시 `.output/server/wrangler.json`이 재생성되므로, 배포 전 반드시 `"placement": { "mode": "smart" }`와 `"services": [{ "binding": "GEMINI_PROXY", "service": "tokbiseo-gemini-proxy" }]`를 다시 적용한 뒤 `npx wrangler deploy --config .output/server/wrangler.json --name talk-secretary`로 배포해야 함.**
- **모바일 구글 포토 첨부 호환성 (`inbox.tsx`):** Android WebView에서 `<input type="file" accept="image/...">` 사용 시 Photo Picker가 떠서 Google Photos 클라우드 사진 읽기(`NotReadableError`)가 실패하는 경우가 있어, 사진 첨부 입력란(`fileRef`)에서도 `accept` 속성을 제거해 시스템 파일 선택기(`ACTION_GET_CONTENT`)가 열리도록 통일함.

## 3. 수익화 및 스토어 통합 업데이트 이력 (2026-11-25 완료)
- Google Play Console 정기결제 상품 `tokbiseo_premium_monthly` (월 3,900원) 및 `tokbiseo_premium_yearly` (연 39,000원) 등록 후 `BILLING_ENABLED = true` 활성화, PWABuilder v2(`.aab`, 1.0.0.0) 빌드 및 프로덕션 정식 출시 완료 (`2026-11-25 17:05 출시됨`).
- **구독 상태 자동 동기화 (`src/lib/play-billing.ts`, `src/components/inbox-extras.tsx`):** `localStorage`의 `plan` 값을 신뢰하지 않고 앱 시작 시 항상 `free`로 초기화한 뒤 `checkPlaySubscription()`(`listPurchases`)으로 실제 구글 정기결제 여부를 확인해 자동 복원. 이미 프리미엄인 경우 `PaymentModal`에서 혜택 및 Play Store 관리 안내 표시, 테스트용 무료 되돌리기 버튼 제거.
- **시작 화면 통일 (`src/routes/__root.tsx`):** v2 앱 아이콘이 비서 얼굴로 통일됨에 따라, 앱 실행 시 두 번 겹치던 웹앱 내부 비서 얼굴 스플래시 오버레이 제거.
- **대표님 계정 테스트 면제 (`ybaehun@gmail.com`):** Supabase `user_metadata.trial_exempt = true` 설정을 통해 일반 사용자는 기존 제한을 유지하면서 대표님 계정만 7일 무료체험·용량·일일 횟수 제한(클라이언트 `quotaErr`/`dailyErr` 및 서버 `assertDailyLimit`)을 모두 면제.
- **다음 이어갈 작업:** 톡비서·오답정복(2026-11-25 동시 출시 상태) 홍보용 15초 숏폼 대본 및 커뮤니티 소개글 제작·실행.
