# 찻잔타로

아늑하고 따뜻한 톤앤매너의 대화형 타로 상담 웹 앱을 만들어줘.

[핵심 기능 및 화면 구성]
1. 메인 홈 화면:
- 따뜻한 차 한 잔을 마주한 듯 아늑한 크림 베이지/웜톤 감성의 UI
- '오늘의 무료 행운 타로 (매일 1회 1장 뽑기)' 카드 영역
- '깊은 고민 상담 시작하기' 버튼 및 고민을 구체적으로 적을 수 있는 텍스트 입력창

2. 상담사 페르소나 선택:
- 다정하고 따뜻하게 안아주는 언니/누나
- 현실적이고 명쾌한 팩트폭행 T 상담사
- 신비롭고 영적인 분위기의 마녀 등 감성적인 페르소나 선택 카드

3. 카드 뽑기 인터랙션:
- 여러 장의 타로 카드 중 직관적으로 3장을 고르는 부드러운 카드 셔플 및 뒤집기 애니메이션

4. 대화형 AI 상담 (핵심 킥):
- 단순히 카드 뜻을 나열하는 것이 아니라, 사용자가 작성한 고민과 3장의 카드를 연계하여 공감하고 위로해주는 1:1 대화형 메신저 화면
- Lovable 내장 AI를 활용해 따뜻한 티키타카 대화 이어가기

5. 오운완 감성의 처방전 카드:
- 상담 종료 시 인스타그램 스토리 규격(9:16)으로 공유할 수 있는 감성 한 줄 처방전 이미지 카드 생성 및 저장 기능
