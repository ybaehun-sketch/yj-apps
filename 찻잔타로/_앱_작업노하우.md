- **문제 원인:** 기존 화면 이동 방식(`signInWithOAuth`)은 데이터 창고 주소(`zgjpszhkiblaqyrukmey.supabase.co`)를 거쳐 가기 때문에 로그인 화면에 복잡한 영문 창고 주소가 노출됨.
- **해결 방식:** `src/routes/auth.tsx`에서 옛 러버블 로그인 통로를 제거하고, 깔끔한 찻잔타로 기본 `Google로 계속하기` 버튼 위에 투명한 구글 공식 로그인 버튼(`accounts.google.com/gsi/client` + `signInWithIdToken` + 보안 난수 검증)을 겹쳐 배치함.
- **구글 설정 허용 주소:** `https://teacuptarot.com`, `http://localhost:8080`, `http://localhost`
- **결과:** 화면에는 개인 프로필 노출 없이 깔끔한 `Google로 계속하기` 기본 버튼이 보이고, 클릭 시 로그인 창에 `'찻잔타로(으)로 이동'`으로 정상 표시됨.
